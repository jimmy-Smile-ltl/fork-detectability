# 研究规范（CONTRIBUTING）

> 本文件是本项目的**方法论纪律**。提交分析代码或报告前请对照检查。
> 这些规则不是风格偏好，每一条都对应一次真实的错误。

---

## 一、数据纪律

| 规则 | 说明 |
|---|---|
| **JSONL 是唯一事实来源** | 索引/数据库只是缓存，必须能从 JSONL 重建 |
| **缺失 ≠ 0** | "没采到" 与 "确实是 0" 必须分开；「无信息」单独成桶 |
| **`own_count == 0` 只在完整采集时成立** | 否则只是采样值 |
| **单页抽样不得外推** | 本项目两次踩坑：时间戳名 36% → 0.42%；同秒碰撞 8.14× → 1.02× |
| **原始数据不公开** | `data/` 全部 gitignore；示例一律脱敏 |

---

## 二、方法论纪律

| 规则 | 说明 |
|---|---|
| **两轴不求和** | 身份自证 × 批量性，禁止合成"可疑度总分" |
| **判据必须独立于分组依据** | 用爆发窗定义批量性，就不能再用爆发窗当判据（循环论证） |
| **时间聚类用局部速率** | 同秒碰撞的期望必须按小时局部速率算，不能用全程平均 |
| **任何比例标注分母** | 每个百分比都要能追溯到 N |
| **不给单个账号公开定性** | 只输出分桶计数与判据区分度 |
| **跨仓比较必须做时间控制** | 两个仓的 fork 龄可能差 20 倍以上 |

## 三、表述纪律

| ✅ 可以说 | ❌ 不可以说 |
|---|---|
| "fork 使用率显著低于对照仓" | "这个仓库在刷量" |
| "增长集中在极少窗口，形态非自然" | "这些账号是机器人" |
| "存在大量低活跃账号" | "这些人收了钱" |
| "在 A 组与 B 组之间零重叠" | "证明了某仓库造假" |

**核心边界**：我们能证明"形态异常"，不能证明"造假动机"。

## 四、采集结果九态

**禁止用 `http=0` 表达"没采到"** —— 它同时代表网络失败、子资源全 404、解析失败三种情况。

| Outcome | 含义 | 终态 | payload |
|---|---|:---:|---|
| `OK` | 200 且有内容 | ✅ | 数据 |
| `EMPTY` | 资源存在但为空（0 仓/0 提交/409 空仓） | ✅ | **值 0** |
| `DELETED` | **账号** 404 | ✅ | `None` |
| `NOT_FOUND` | **子资源** 404 | ✅ | `None` |
| `PRIVATE` | 403 非配额 | ✅ | `None` |
| `AUTH` | 401 | ✅ | `None` |
| `RATE_LIMIT` | 403/429 配额 | ❌ 重试 | — |
| `NETWORK` | 连接失败/超时/5xx | ❌ 重试 | — |
| `BAD_RESPONSE` | 200 但解析失败 | ❌ 重试 | — |

**三条硬规则**

| 规则 | 说明 |
|---|---|
| **终态只采一次** | 记墓碑，重跑直接跳过 |
| **`EMPTY` 是 0，`DELETED` 是 `None`** | 混成 0 会让零提交率失真 |
| **写入优先级 `OK > EMPTY > 终态 > 可重试`** | 一次成功后，后来的失败不得覆盖 |

## 五、合规要求

| 要求 | 说明 |
|---|---|
| **匿名只读** | 不使用 token、不登录、不使用任何人的会话 cookie |
| **拒绝 cookie** | 若使用者粘贴了会话 cookie，提示 revoke，且绝不使用 |
| **邮箱只落布尔** | 不存明文邮箱 |
| **不采集 star/watch 名单** | 该数据仅仓库所有者可读，本项目承诺匿名只读故不取 |
| **密码永不落盘** | 代理凭据只从环境变量或本地 gitignored 文件读取 |
| **不公开账号名单** | 任何文档中的 login 一律脱敏为前 3 位 |

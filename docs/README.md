## archive/ 是什么

`archive/` 里是 **9 份历史设计文档**（2026-10 ~ 11 初），已被上面这些文档取代。

保留原因：它们记录了「当时为什么这么设计」，以及**哪些设计后来被数据推翻**。
例如 `用户真人评分设计.md` 里的负向证据表（三零形态 −20 分）已被实证推翻。

> ⚠️ **不要引用 archive 里的数字**——里面的多数结论已被证伪，
> 正确值以 `01_研究报告.md` 与 `05_指标设计清单.md` 为准。

## archive/ 是什么

`archive/` 里是 **9 份历史设计文档**（2026-10 ~ 11 初），已被上面这些取代。
保留原因：记录了"当时为什么这么设计"，以及**哪些设计后来被数据推翻**。

> ⚠️ **不要引用 archive 里的数字** —— 多数结论已被证伪。

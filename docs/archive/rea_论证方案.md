## 一、为什么主对照只能是 openclaw

| 维度 | openclaw | rea | 可比性 |
|---|---:|---:|---|
| ★ | 392,928 | 377,714 | **同量级（差 4%）** |
| fork | 82,588 | 94,367 | 同量级 |
| watch | 1,705 | 1,345 | 同量级 |
| 仓龄 | ~335 天 | 194 天 | 同一时代 |
| 类型 | AI 工具/Agent | AI 工具 | 同类 |
| fork 名单 | **82,176 条（全量）** | 200 条（0.2%） | ❗不对称 |
| forker 画像 | 2,700 人 D1 | 0 | ❗不对称 |
| CH star 身份 | 105,696（26.9%，全年） | 5,921（**仅 10 月**） | ❗不对称 |

**为什么不用 ollama / n8n 当主对照**：它们规模差 1–2 个数量级，规模效应会污染比例类指标
（issue/千★、fork÷star 都随规模变）。openclaw 是唯一"同规模、同时代、同类型"的仓。

**但必须声明**：openclaw **不是干净基线**——它自己的 star 增速至今未解释，
本项目结论是「一人 + AI 作者驱动型」。所以它的定位是**同规模参照**，不是"正常样本"。
凡两仓差异，措辞只能是「rea 偏离 openclaw」，不能是「rea 异常，因为 openclaw 正常」。

## 五、执行顺序（三步，每步可独立停）

**Step 1 · 采名单**（唯一需要联网的一步）

采集器：`_forks_kdl_collect.py`（快代理版，与 本机代理版**共用同一份文件、游标、去重键**，可随时互切）。

配置契约（二选一，**都不入仓库**）：

```jsonc
// data/proxy_kdl.json（已 gitignored）
{
  "api_url": "https://dps.kdlapi.com/api/getdps/?secret_id=...&signature=...&num={num}&sep=1",
  "username": "...",
  "password": "..."
}
```
或环境变量 `KDL_API_URL` / `KDL_USERNAME` / `KDL_PASSWORD`（优先级更高）。

三步：先离线校验 → 再花 3 个请求验证出口 → 最后全量：

```powershell
py _forks_kdl_collect.py --repo morluto/rea --dry-run    # 不联网，只查配置/游标
py _forks_kdl_collect.py --repo morluto/rea --probe      # 取 1 批 IP + 试 1 页
py _forks_kdl_collect.py --repo morluto/rea              # 全量，断点续采，Ctrl-C 可停
```

预期：822 页 openclaw 当年 20–25 分钟跑完，rea 944 页约 **25–35 分钟**，
每 25 页轮换一批 5 个出口、1.2s/页节流。全失败时**不发直连请求**（直连只 60/h，会把工期拖回几十小时）。

**Step 2 · 出对照表**（0 请求）
```powershell
py metrics_fork.py --all --until 2026-10-24
```
`--until` 是**必须**的：两仓名单采集时点不同（openclaw 10-24 / rea 11-06），
不截断会把"多出来的十来天"算进爆发窗和同秒富集。

**Step 3 · 定向画像**（800–1,200 req，只采可疑簇）
对 rea 名单里 `TS` / `PHONE` 形态 + 爆发窗内账号抽 200–300 人，
`_profile_tiers.py --tier minimal`（4 req/人）→ 补 `SAAR`、自建仓、蒸发率。

## 六、对齐规则（保证两仓可比）

1. **时间同窗**：所有时间相关指标一律 `--until 2026-10-24`，并在报告里写明窗口
2. **同一实现**：两仓用同一个 `metrics_fork.py`、同一 spec 版本、同一参数（3h / 2σ / 60s）
3. **同时报分母**：每个比例必须带 `n` 与覆盖率（rea 的名单覆盖率会在采集中从 0.2% → 100%）
4. **只比比例与 lift，不比绝对值**：行数差异有 12%（82,176 vs 94,367），绝对数天然不可比
5. **未采到 = insufficient_data**，绝不填 0
6. **CH 侧窗口差异必须声明**：openclaw 覆盖全年、rea 只有 2026-10，行为宽度对比只能标"方向性"

1. **「爆发后归零」不成立**（原 `data/out/new_repos_analysis.md` 的表述已过期）。

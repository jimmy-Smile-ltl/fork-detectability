## 二、绘图的技术约定

### 2.1 中文字体必须显式设置

```python
import matplotlib
matplotlib.rcParams["font.sans-serif"] = ["Microsoft YaHei", "SimHei", "DejaVu Sans"]
matplotlib.rcParams["axes.unicode_minus"] = False   # 负号显示
```

**不设会变成方块。** 若系统无中文字体，脚本会降级为英文标签（不报错）。

### 2.2 CDF 的零值必须裁剪

```python
# ❌ 错误：filter(d > 0) 会把"同秒"排除，中位数从 0 变成 144 小时
# ✅ 正确：裁剪到最小正值
d = max(d, 0.002)   # 7.2 秒，比 1 秒的显示精度略大
```

**这个 bug 曾导致 openclaw 的曲线整条消失。**

### 2.3 象限图的标签顺序必须与数据一致

```python
labels = [("高","高"), ("高","低"), ("低","高"), ("低","低")]
x = [1, 1, 0, 0]      # 第一维：自证
y = [1, 0, 1, 0]      # 第二维：批量性
```

**曾出现标签与数据错位**（右上角画的是"低-低"象限）。

### 2.4 样本量必须标在图上

每个百分比旁边标 `n=xxx`，或在图注里写清分母。
**这是本项目的硬规则**（AGENTS.md §四）。

### 2.5 颜色约定

| 颜色 | 含义 | 色值 |
|---|---|---|
| 红 | rea（可疑主体） | `#d62728` |
| 蓝 | openclaw（对照） | `#1f77b4` |
| 灰 | 中性/参照线 | `#999999` |

## 三、报告生成流程

### 3.1 完整管线

```
data/raw/*.jsonl                 ← 原始采集（不可变事实层）
        │
        ├─┬─ 1. 特征工程 ─────────────────────────────
        │ │   scripts/analysis/_compute_all_features.py   → features_rea.csv / features_openclaw.csv
        │ │   scripts/analysis/_compute_bettafish.py      → features_bettafish.csv
        │ │   scripts/analysis/_compute_any.py            → features_{对照仓}.csv
        │ │
        │ ├─ 2. 判据计算 ─────────────────────────────
        │ │   scripts/analysis/_effective_indicators.py    → 12 个判据（带分子分母）
        │ │   scripts/analysis/_internal_burst_control.py  → 同仓内部对照
        │ │   scripts/analysis/_compare_three.py           → 多仓对照
        │ │
        │ ├─ 3. 图表 ─────────────────────────────────
        │ │   scripts/figures/_plot_fork_timeline.py       → 图 1–3
        │ │   scripts/figures/_make_figures.py             → 图 4–14
        │ │   scripts/figures/_make_time_control_figures.py→ 图 12–13
        │ │
        │ ├─ 4. 数据文档 ─────────────────────────────
        │ │   scripts/analysis/_data_volume.py             → data_volume.md
        │ │   scripts/analysis/_audit_gaps.py              → gap_audit.md
        │ │   scripts/analysis/_make_samples.py            → 13_采集结果示例.md
        │ │   scripts/analysis/_make_profile_demo.py       → 14_账户画像demo.md
        │ │
        │ └─ 5. 报告（人工撰写，数据驱动）
        │     docs/01_研究报告.md      ← 主报告
        │     docs/02_图文报告.md      ← 图文版
        │     docs/11_真人判别指标手册.md ← 指标参考
```

### 3.2 一键复现（除采集外全离线）

```bash
# 1) 特征表（三仓）
python scripts/analysis/_compute_all_features.py
python scripts/analysis/_compute_bettafish.py
TAG=shardeum FORKS=forks_all_shardeum__shardeum.jsonl TARGET=shardeum python scripts/analysis/_compute_any.py

# 2) 判据
python scripts/analysis/_effective_indicators.py
python scripts/analysis/_internal_burst_control.py
python scripts/analysis/_compare_three.py

# 3) 图表
python scripts/figures/_plot_fork_timeline.py
python scripts/figures/_make_figures.py
python scripts/figures/_make_time_control_figures.py

# 4) 数据文档
python scripts/analysis/_data_volume.py
python scripts/analysis/_audit_gaps.py
python scripts/analysis/_make_samples.py
python scripts/analysis/_make_profile_demo.py
```

**全部本地计算，0 网络请求。**

### 3.3 报告的写作纪律

| 规则 | 说明 |
|---|---|
| **每个百分比带分母** | `6.4% (3,136/49,289)`，不是裸的 6.4% |
| **异常 ≠ 造假** | 只能说"形态异常"，不能说"异常增长" |
| **不列入** | 只输出群体统计，不对单个 login 定性 |
| **证伪也要写** | 21 个被证伪的判据必须完整列出 |
| **记录自己的错** | 三次口径反复、单页抽样外推等必须留档 |

## 四、图文报告的结构（`02_图文报告.md`）

```
序言：两个仓库的价值
  ↓
图 1–3   时间轴（形态长什么样）
  ↓
表 1     12 个判据的完整数值
  ↓
图 4     判据效应量排名
  ↓
图 5–9   各维度分布
  ↓
图 10    两轴四象限
  ↓
图 12–13 时间控制实验
  ↓
图 14    头像 vs 账号年龄
  ↓
结论     没有找到造假证据
```

**每张图下面必有一句话结论**，不让读者自己猜。

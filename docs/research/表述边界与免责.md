## 一、本项目的目的是什么（以及不是什么）

### 1.1 目的

> **研究「用公开数据判断 GitHub 仓库 fork 行为是否异常」这件事的方法与边界。**

具体是三件事：

1. **方法学**：建立一套可复现的采集与分析流程（8 维度 × 8 仓库）
2. **实证**：用已知案例检验这套方法的检出能力
3. **结论**：诚实地说明它**能**证明什么、**不能**证明什么

### 1.2 不是目的

| ❌ 不是 | 原因 |
|---|---|
| 指控任何仓库造假 | 我们没有、也不可能有判定权 |
| 举报或曝光任何项目 | 不是举报材料 |
| 给任何账号定性 | 只做群体统计，不做个体结论 |
| 证明"某项目在刷量" | **公共数据无法证明动机** |

## 二、关于本文中的"对照组"（最容易误解的部分）

### 2.1 它们为什么被列为 A 组

本文的 **A 组**（3 个仓库）**不是我们判定的**，而是：

> **引用了第三方公开发表的研究结论。**

具体来源：

| 仓库 | 外部来源 | 该来源的措辞 |
|---|---|---|
| shardeum/shardeum | StarScout 研究（arXiv:2412.13459） | "suspected fake stars" |
| unionlabs/union | 同上 | 同上 |
| anoma/anoma | 同上 | 同上 |

**关键事实**：

1. 该研究使用的是**统计判定**，其原文用词是 **"suspected"（疑似）**
2. **相关项目方可能否认，这完全正当**
3. 我们**没有**独立验证这些仓库是否存在星标异常
4. 我们**只是**把这些仓库当作"外部研究提供了另一种样本"来做方法学对照

### 2.2 因此本文的正确读法

| ❌ 错误读法 | ✅ 正确读法 |
|---|---|
| "本文认定 X 仓库造假" | "本文引用外部研究，把 X 归入 A 组做对照" |
| "A 组的 forker 是假号" | "A 组仓库的 forker 在某些指标上分布不同" |
| "X 项目在刷量" | "X 项目被外部研究列为疑似案例" |

### 2.3 我们对 A 组仓库的正面评价同样成立

**A 组的三个仓库都是真实存在的、有实际代码的区块链/加密项目。**

本研究不否认它们的工程价值。它们被选入 A 组，
**仅仅因为外部研究把它们列为疑似案例**，这与它们的代码质量无关。

## 三、绝对不做的四件事

| # | 禁止 | 说明 |
|--:|---|---|
| 1 | **不点名指控** | 只输出群体统计，不对任何单个 login 定性 |
| 2 | **不发布账号名单** | 采集数据不公开，报告只给聚合数字 |
| 3 | **不使用"造假"作为结论** | 最多说"形态异常"、"分布不同" |
| 4 | **不推断动机** | 不推测谁付钱、谁收钱、为什么 |

## 四、统一措辞表（写任何文档时必须遵守）

| ❌ 禁止使用 | ✅ 应当使用 |
|---|---|
| 这个仓库在刷量 | 该仓库的 fork 时间分布高度集中 |
| 这些是假号 | 这批账号在 X 指标上的分布与 B 组不同 |
| 证明了造假 | 观测到形态差异；**无法证明动机** |
| A 组造假仓 | A 组（外部研究列为疑似） |
| B 组干净仓 | B 组（无相关报道） |
| 高端刷量 | 高成本操作特征 |
| 买星 / 刷星 | 星标异常 |
| 作弊 | 非常规操作 |
| 注水 | 数值虚高 |

## 五、本研究真正的结论（一句话）

> **8 个仓库、25.3 万个 forker、223 万条记录之后，
> 我们发现：**
>
> **① 单条判据几乎全部不可靠**（21 个被判据在早期就被证伪）
> **② 组合指标（四级质量分层）才是唯一稳定的工具**
> **③ 公共数据能识别"形态差异"，不能证明"主观造假"**
>
> **这不是对任何项目的指控，而是一份关于"方法边界"的研究。**

**请以本文件为准。**

任何把本文解读为"指控某项目造假"的说法，都**超出了本文的原意与证据范围**。

## 七、数据与隐私

| 项 | 做法 |
|---|---|
| 采集方式 | 匿名只读，不使用 token、不登录、不使用 cookie |
| 邮箱 | 只落布尔值，不存地址 |
| 账号名单 | **不在任何文档中公开**（示例一律脱敏为前 3 位） |
| 原始数据 | `data/` 已 gitignore，不随代码发布 |
| 对照组仓库 | 仅引用外部公开研究，不做独立定性 |

## 一、先说清楚：什么情况下"造假动机"最强

星标/复刻的价值不在技术，而在**它被谁当作决策依据**。按激励强度排序：

| 激励类型 | 谁在看 star | 造假收益 | 典型仓库类型 |
|---|---|---|---|
| **① 融资 / 估值** | VC 尽调、TS 谈判 | **极高**（直接影响估值） | AI agent 框架、基础设施 |
| **② 代币 / 空投 / 上所** | 交易所、社区 | **极高**（影响上币与定价） | 加密项目（已采 shardeum/union/anoma） |
| **③ 个人品牌变现** | 招聘方、咨询客户、课程购买者 | 高 | skill 包、方法论、教程 |
| **④ 平台激励** | GitHub Sponsors、赏金榜 | 中 | 通用工具 |
| **⑤ 纯注意力** | 媒体、同行 | 低 | "awesome" 清单、玩具项目 |

**结论：应优先采 ① 和 ③。** 加密类（②）已有 3 个样本。

## 三、核心发现：**"后 AI 时代"的爆火仓，watchers/★ 系统性偏低**

| 群体 | w/★ 中位 | 范围 |
|---|---:|---|
| **原有 11 仓**（多数 2023 前建立） | **0.57%** | 0.18–2.17% |
| **新候选 22 个**（2025–2026 建立） | **约 0.35%** | **0.094–1.78%** |

**这不能直接当作造假证据** —— 它更可能是**"注意力型仓库"的结构特征**：
- 星标成本极低（看到一条推文就点）
- 订阅（watch）需要主动选择接收通知，门槛高
- 越是"看一眼就够了"的内容（skill 包、白嫖工具、清单），watchers/★ 越低

> **所以：watchers/★ 低是"仓库类型"信号，不是"造假"信号。**
> 只有**远低于同类**的才值得注意。

## 七、必须提醒的三点

| # | 提醒 |
|--:|---|
| 1 | **"激励强"是选择理由，不是结论** —— 不能因为一个仓在融资就说它刷量 |
| 2 | **这些仓都很新（100–400 天）** —— fork 龄短，`fork_touched` 等判据必须做时间控制 |
| 3 | **skill / 配置类仓库的 fork 动机与代码项目不同** —— 用户 fork 是为了复制配置，这会让 `has_own` / `commit_zero` 的解释变复杂 |

**建议第一批只采前 3 个（A 侧），看信号是否值得继续。**

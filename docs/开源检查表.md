### 3.2 链接有效性

```bash
python - <<'PY'
import os, re
bad = total = 0
for root, _, fs in os.walk("."):
    if ".git" in root.split(os.sep): continue
    for f in fs:
        if not f.endswith(".md"): continue
        p = os.path.join(root, f)
        s = open(p, encoding="utf-8", errors="replace").read()
        for m in re.finditer(r"\]\(([^)\s]+?\.md)(?:#[^)]*)?\)", s):
            t = m.group(1); total += 1
            if not os.path.exists(os.path.normpath(os.path.join(root, t))):
                bad += 1; print("失效:", p, "->", t)
print(f"共 {total} 条，失效 {bad} 条")
PY
```

**期望**：`失效 0 条`。

## 五、数据可复现性方案（三选一）

| 方案 | 做法 | 优缺点 |
|---|---|---|
| **A. 只开源代码**（当前） | 数据完全不提供，任何人自行复现 | ✅ 最安全<br>❌ 复核成本高 |
| **B. 提供聚合统计** | 只发布「每仓每判据的分子/分母」，约几十 KB | ✅ 可复核结论<br>✅ 无个人隐私<br>⭐ **推荐** |
| **C. 提供脱敏样本** | 每仓随机 500 个账号，去掉 login | ✅ 可验证数据结构<br>❌ 仍可能间接识别 |

**建议**：采用 **B**。当前仓库仍为方案 A，聚合统计表尚未导出；若要让外部复核结论，这是发布前最值得补的一项。导出格式示例：

```
repo, judge, numerator, denominator
shardeum, has_pull_shark, 82, 682
...
```

这个表足以让任何人**独立复算所有判据和置信区间**，且不含任何个人信息。
